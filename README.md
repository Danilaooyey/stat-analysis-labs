# Лабораторные по статистическому анализу

Морозов Данил, группа 6311. Первая часть каждой лабораторной. В ЛР № 4 и № 6 использован вариант 14, в ЛР № 5 — согласованный лист «ВАРИАНТ 13».

## Быстрый запуск

Скачайте репозиторий через **Code → Download ZIP** и распакуйте в доступную для записи папку. Нужен Python 3.12–3.14. Откройте терминал в распакованной папке.

```powershell
py run.py all --no-show
py run.py 4
py run.py 5
py run.py 6
```

На macOS и Linux замените `py` на `python3`. Без `--no-show` скрипты открывают окна графиков, если доступен графический интерфейс. Таблицы выводятся в терминал и сохраняются в `labN_output.txt` внутри папки работы.

При первом запуске `run.py` создаёт `.venv` и устанавливает зависимости из `requirements.txt`. На Windows x64 он также скачивает портативный Gretl в `.tools`, если не находит установленный. Для первого запуска нужен интернет. На Linux и macOS для работ № 5 и № 6 предварительно установите Gretl и добавьте `gretlcli` в PATH или задайте переменную `GRETLCLI` с полным путём к исполняемому файлу. Работа № 4 запускается без Gretl.

Окружение `.venv` создаётся заново при распаковке в другом месте. Подготовленные зависимости и Gretl повторно используются при следующих запусках из той же папки.

- [Gretl для Windows](https://gretl.sourceforge.net/win32/)
- [Gretl для macOS](https://gretl.sourceforge.net/osx.html)
- [Пакет Gretl для Ubuntu](https://packages.ubuntu.com/gretl)

## Что находится в папках

| Папка | Что считает скрипт | Что сохраняется |
|---|---|---|
| [lab4](lab4) | Описательная статистика, нормальность, сравнение СКФО с ЮФО и РФ, парное сравнение 2010–2020 | Гистограммы и боксплоты |
| [lab5](lab5) | Три МНК-модели, диагностика остатков, прогноз и симуляция гетероскедастичности с поправкой HC3 | График остатков и Excel с синтетическими данными |
| [lab6](lab6) | Регрессии зарплаты, 91%-е интервалы, проверка предпосылок, сравнение МНК, HC3 и ВМНК | Q–Q график остатков |

В каждой папке лежит исходный Excel и собственный `requirements.txt`. Если скачали только одну папку, установите зависимости командой `python -m pip install -r requirements.txt` в своём окружении и запустите соответствующий `labN_part1.py`. Для № 5 и № 6 при таком запуске нужен доступный `gretlcli`.
